    Simulationen & Visualisierungen¶

    Alle Grafiken und Videos unter docs/ werden automatisch erzeugt (visualize_network.py, visualize_flow.py, make_*.py), sodass sie jederzeit neu generiert werden können.

    Gesicht Gesichtserkennung InsightFace-Match gegen faces.json (Elon Musk) ~12 s
    Fahndung Fahndung echter Cosinus-Match gegen fahndungen.json ~9 s
    Waffen Waffenerkennung echte Gun-Erkennungsaufnahme ~26 s
    Dieb Dieberkennung echter Pose-Code (COCO-17-Keypoints + Loitering + Geste) auf vid_dieb_guard.mp4 ~32 s
    Web-App Web-App Dashboard-Mockup mit Waffen-Alarm ~7 s
    Auto Track Personenverfolgung komplette PTZ-Track-Schleife ~59 s

    Dieberkennung¶

    Mit dem echten Pose-Code (dieb_erkennung/pose_detector.py) wird die vorhandene Aufnahme dieb_erkennung/output/vid_dieb_guard.mp4 verarbeitet — kein neues Video, keine Fake-Animation. Das Ergebnis zeigt das COCO-17-Keypoints-Skelett, Loitering-/Gestenbewertung und das rote Verdachts-Banner bei echten Treffern (Protokoll: simulationen/dieb_simulation_result.json).

    Neu erzeugen¶

    cd C:\Users\youss\Desktop\UtutCam\docs
C:\Users\youss\AppData\Local\Python\pythoncore-3.14-64\python.exe make_diagrams.py      # Netzwerk-Diagramme
C:\Users\youss\AppData\Local\Python\pythoncore-3.14-64\python.exe make_flows.py        # Ablauf-Diagramme
C:\Users\youss\AppData\Local\Python\pythoncore-3.14-64\python.exe make_simulations.py  # Videos (echte InsightFace-Matches + Dieb-Pose-Code)

    Waffen-Video wird aus einer vorhandenen echten Aufnahme (data/results/) übernommen; die Dieb-Simulation erzeugt make_simulations.py mit dem echten Pose-Code aus dieb_erkennung/output/ (vid_dieb_guard.mp4). Gesicht/Fahndung nutzen echte Embeddings von InsightFace.
