    Willkommen zur UtutCam-Dokumentation¶

    Direkt starten

    Die gesamte Analyse-Strecke läuft lokal in einem Befehl:

    cd C:\Users\youss\Desktop\UtutCam
C:\Users\youss\AppData\Local\Python\pythoncore-3.14-64\python.exe web_app\server.py

    Danach im Browser: http://localhost:5000

    Willkommen zur Dokumentation von UtutCam — einem Edge-basierten Live-Video-Analyse- und Alarmsystem. Die Software verarbeitet das Bild einer IP-Kamera in Echtzeit und kombiniert Personenverfolgung (Auto Track), Gesichtserkennung, Waffenerkennung, Dieberkennung und den Bundespolizei-Fahndungsabgleich in einem integrierten System — steuerbar über ein Browser-Dashboard und eine REST-API.

    Loslegen Installation Repository auf GitHub

    Was ist UtutCam?¶

    UtutCam analysiert das Live-Videobild einer IP-Kamera (RTSP) lokal auf dem eigenen PC — das Videobild verlässt das eigene Netzwerk nie. Für jede Funktion liefert das System ein konkretes Ergebnis: Alarm, Screenshot, Live-Stream oder REST-Antwort.

    • Auto Track

      Der Detektor erkennt eine Person, die PTZ-Kamera schwenkt und hält sie automatisch mittig im Bild. Aufnahme startet voll- oder halbautomatisch.

      Details

    • Gesichtserkennung

      InsightFace erzeugt 512-dim-Embeddings und gleicht sie gegen die lokale Gesichtsdatenbank ab (Cosine-Similarity).

      Details

    • Waffenerkennung

      YOLOv8-Modelle für Schusswaffen, Hände und Messer mit Konfidenz-Ausgabe und Fehlalarm-Filter (hand_cover ≥ 0.35).

      Details

    • Dieberkennung

      Personen-Tracking über die Zeit (IOWA/Loitering-Analyse) erkennt verdächtiges Verhalten und löst Alarm aus.

      Details

    • Fahndung

      Automatischer Abgleich gegen die Bundespolizei-Fahndungsliste — bei Treffer Telegram-Benachrichtigung und Screenshot.

      Details

    • Web-App & REST-API

      Browser-Dashboard mit Live-MJPEG-Stream, Modul-Schaltern, Event-Log und vollständiger REST-API für alle Funktionen.

      Details

    Die Modelle¶

    Die neuronalen Netze wurden teils auf Google Colab trainiert und liegen als Ultralytics-.pt bereit:

    Modell Inhalt
    UtutGun.pt Schusswaffen
    UtutHand.pt / UtutHand2.pt Hände
    UtutBest.pt Waffen + Hände + Messer
    UtutPerson.pt Personen (Dieb- / Auto-Track-Grundlage)
    InsightFace buffalo_l Gesichts-Embeddings (512-dim)

    Modelle werden über das GitHub-Release v1 (NovaAixYoussef/ututcam-models) bereitgestellt. Siehe Installation und Struktur.
